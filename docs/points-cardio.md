# Cardio points

How run and swim are scored. Overview: [points.md](points.md). The ladder behind the numbers: [points-foundation.md](points-foundation.md).

## Principle: equal time at equal effort

A minute of cardio pays what a minute of lifting pays when the effort is the same. This is the session-RPE idea (load = effort × minutes), which is validated across lifting and endurance training. Equal energy is not used, because a mile of running burns about as much as 250 push-ups and would let cardio dwarf everything else. "Equal difficulty by feel" has no formula behind it.

There is no scientific exchange rate between strength and cardio, so the rate is a convention. This one is explainable and anchored to data. A mile's price is the lifting rate times the minutes a mile takes at a reference pace.

## The lifting rate: 51.4 points a minute

**Lifting rate = points per set ÷ minutes per set = 180 ÷ 3.5 = 51.43.**

- **Points per set: 180.** The ladder's value for an all-out set at the midpoint of Novice and Intermediate (the average of 120 and 240), the same centre used for bodyweight prices ([points-foundation.md](points-foundation.md)).
- **Minutes per set: 3.5.** The ACSM position stand recommends 2-3 minutes of rest between sets for 8-12 rep work (1-2 minutes for novices), and a set itself takes about 30 seconds (Nuzzo et al. report rep durations of 1.4-6 seconds). A set-plus-rest cycle is therefore 2.5-3.5 minutes, and 3.5 is the top of that range, which leaves room for transitions between exercises. Wall-clock time, rest included, is the right basis. Over 3.0 to 4.0 minutes a set the rate is 60 to 45 points a minute.
- **Effort.** The reference effort is a set taken to failure. If a typical set stops a couple of reps short, the rate is about 10% lower.

## Run: 521 points per mile

Distance is a fair measure for running because energy per mile is about constant at any pace (roughly 1 kcal per kg per km).

**Reference pace: 10:08 per mile**, the men's median 5K pace from RunRepeat (the reference lifter is a 150 lb man). 51.43 × 10.13 min = **521.1 per mile**.

## Swim: 103 points per 100 yd (1.029 a yard)

Swimming is not like running: energy per distance varies a lot with skill, and swimming costs about 3-4 times running per unit distance. Distance is used anyway, for consistency with the run.

**Reference pace: 2:00 per 100 yd**, the boundary between "Fair" (500-599 yd) and "Good" (600-699 yd) in 12 minutes for men aged 20-29 in the Cooper 12-minute swim test norms (Cooper, 1982, as tabulated by [Topend Sports](https://www.topendsports.com/testing/tests/swim-12-minutes.htm)). 51.43 × 2.0 min = **102.9 per 100 yd**. The Cooper table gives ratings, not percentiles, so taking the Fair/Good boundary is a judgement; the middle of "Fair" (2:11) would give 112.

Yards are the unit. Meters are converted at × 1.0936, so the same pool distance pays the same.

**Consistency check.** A swimming mile (1,760 yd) pays 1,810, which is 3.5 times a running mile (521): the middle of the 3-4 times range the energy-cost literature gives. This is a check, not an input.

The 2018 U.S. Masters Swimming 1-Hour ePostal Championship (590 men; median 1:35 per 100 yd) describes committed competitive swimmers and is not used as a reference.

## Guards

- A single entry is capped at 50 miles of running or 10,000 yd of swimming. This is a typo guard (100 for 10 would silently add thousands of points), not a daily cap.
- There is no daily cap: distance is the only input, and a cap on a self-reported number prevents nothing.

## Limits

- **The rate rests on a convention** (equal time at equal effort) and on a set cycle time that is bounded by guidelines, not measured for this group.
- **Easy long runs are overpaid for their effort** and hard 5Ks are underpaid, because distance-only logging cannot see effort.
- **Swim skill bias:** faster swimmers earn more per minute at the same effort.
- **Short pools:** a 10-yard pool with a push-off every 10 yd gives free distance, so distance there is cheaper than in a 25-yard pool.
- **The swim reference pace** depends on taking the Fair/Good boundary of a rating table.
